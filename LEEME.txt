CÓMO PUBLICAR EN GITHUB
-----------------------
Opción A — Web de GitHub (más fácil):
  1. Guarda una copia de tu versión actual por seguridad.
  2. En tu repo donjapo44.github.io, sube TODO respetando las carpetas
     (index.html y support.js en la raíz; las subcarpetas tal cual).
  3. Pon tus imágenes dentro de images/.
  4. "Commit changes". En 1–2 min se publica en https://donjapo44.github.io

Opción B — Terminal con Git:
  git clone https://github.com/donjapo44/donjapo44.github.io.git
  cd donjapo44.github.io
  # copia aquí el contenido de esta carpeta, respetando subcarpetas
  git add .
  git commit -m "Subtitulos rediseñados (sin // ni guion)"
  git push origin main
